# Онлайн-пошук вправ (exerciseapi.dev) — як увімкнути

Це **необовʼязкова** функція. Без неї працює вся локальна бібліотека (free-exercise-db,
880 вправ, офлайн). Онлайн-пошук додає ще ~2200 вправ із exerciseapi.dev (сила, йога,
мобільність, фізіотерапія тощо) з порадами, типовими помилками й нотатками безпеки —
але тягне їх із мережі в реальному часі.

> ⚠️ Потрібен **API-ключ exerciseapi.dev**. Безкоштовний тариф — **100 запитів/день**
> на весь додаток (усі пристрої разом). Кожен пошуковий запит = 1 звернення; результати
> кешуються на пристрої на 24 год, тож повторні відкриття безкоштовні.

---

## Крок 1. Отримати ключ exerciseapi.dev

1. Зайди на **exerciseapi.dev** → **Get API key** (безкоштовний тариф, без картки).
2. У дашборді скопіюй свій ключ (формат виду `…`, заголовок `X-API-Key`).

---

## Крок 2. Створити функцію exdb у Supabase

1. Відкрий проєкт `gym-start` на **supabase.com** → **Edge Functions** → **Deploy a new function** → **Via Editor**.
2. Виділи весь шаблонний код (Ctrl+A) і видали.
3. Встав уміст файлу **`exdb/index.ts`** з архіву.
4. Внизу зміни **Function name** на **`exdb`** (саме так — інакше додаток не знайде функцію).
5. **Deploy function**.

> Захист `verify_jwt` лишається увімкненим за замовчуванням — це правильно: онлайн-пошук
> працює лише після входу в акаунт, тож твій ключ exerciseapi.dev не витрачають анонімні боти.

---

## Крок 3. Додати секрет із ключем

1. **Edge Functions** → вкладка **Secrets** (або Settings → Edge Functions → Secrets).
2. **Add new secret**:
   - Name: `EXERCISEAPI_KEY`
   - Value: твій ключ із Кроку 1
3. Save.

---

## Крок 4. Користування

1. Відкрий **Бібліотеку** → кнопка **«🌐 Онлайн-пошук (exerciseapi.dev)»**.
2. Введи запит **англійською** (напр. `bench`, `squat`, `plank`, `yoga`).
3. У картці результату **«Деталі»** — опис, інструкції, поради, типові помилки, безпека.
4. **«💾 Зберегти до себе»** — вправа копіюється у твої «свої вправи» (`s.myEx`) і далі
   доступна офлайн та для додавання в плани, як будь-яка своя.

---

## Чому саме так (і що каже ліцензія)

- Дані exerciseapi.dev **не можна перероздавати** іншим користувачам — кеш дозволений лише
  на пристрої. Тому вони **не запікаються** у `exercises.json` і не синхронізуються між
  акаунтами; кожен пристрій тягне й кешує сам. Коли ти тиснеш «Зберегти до себе», ти робиш
  **локальну копію** для власного вжитку — це в межах умов.
- Зображень у exerciseapi.dev поки майже нема (відео — лише для частини вправ), тож збережена
  вправа зазвичай **текстова** (назва + інструкції + поради), можливо без картинки. Це нормально.

## Якщо не працює

| Повідомлення | Що робити |
|---|---|
| «Функцію exdb ще не задеплоєно» | Перевір назву функції — має бути точно `exdb` |
| «Спершу увійди в акаунт» | Онлайн-пошук лише після входу |
| «Ліміт запитів вичерпано» | Вичерпано 100/день безкоштовного тарифу — зачекай або постав платний тариф |
| «Помилка мережі (HTTP_500)» | Не доданий/хибний `EXERCISEAPI_KEY` у секретах |

Логи: **Edge Functions → exdb → Logs**.
