# Розпізнавання вправи по фото — як увімкнути

Це **необовʼязкова** функція. Без неї працюють усі інші способи додавання вправ
(пошук, опис українською, відео, своя вправа з фото).

> ⚠️ Потрібен **платний ключ Anthropic API**. Одне розпізнавання коштує приблизно
> сотні частки цента, але ключ треба поповнювати. Без ключа функція просто не працюватиме,
> решта додатка — так.

---

## Крок 1. Отримати ключ Anthropic

1. Зайди на **console.anthropic.com** → зареєструйся.
2. **Billing** → поповни баланс (мінімум зазвичай 5 USD).
3. **API Keys** → **Create Key** → скопіюй (показується один раз!).

---

## Крок 2. Створити функцію в Supabase

1. Відкрий свій проєкт `gym-start` на **supabase.com**.
2. Ліворуч → **Edge Functions** → **Deploy a new function** → **Via Editor**.
3. У файлі `index.ts` **виділи весь шаблонний код (Ctrl+A) і видали** — це просто приклад «Hello».
4. Встав уміст файлу **`recognize/index.ts`** з архіву.
5. Внизу зміни **Function name** на **`recognize`** (саме так, інакше додаток не знайде функцію).
6. Натисни **Deploy function**.

Файл має лишитись один — `index.ts`. Нічого додавати не треба.

> Шаблон у редакторі використовує новий пакет `@supabase/server` (`withSupabase`).
> Наш код написаний на стандартному `Deno.serve` — це теж повністю підтримуваний спосіб.

---

## Крок 3. Додати секретний ключ

1. **Edge Functions** → вкладка **Secrets** (або Settings → Edge Functions → Secrets).
2. **Add new secret**:
   - Name: `ANTHROPIC_API_KEY`
   - Value: твій ключ із Кроку 1
3. Save.

Необовʼязково: секрет `ANTHROPIC_MODEL` — щоб змінити модель.
За замовчуванням `claude-haiku-4-5-20251001` (дешевша).
Для точнішого розпізнавання можна поставити `claude-sonnet-5`.

---

## Крок 4. Безпека — нічого налаштовувати не треба

Перевірка `verify_jwt` у Supabase **увімкнена за замовчуванням**: платформа перевіряє заголовок
`Authorization` ще до запуску коду функції й очікує дійсний токен користувача. Якщо токена немає —
одразу 401, і функція навіть не запускається (тобто твій ключ Anthropic не витрачається).

Тому окремий перемикач шукати **не потрібно** — захист уже діє.
У новому редакторі при створенні функції його й немає; побачити налаштування можна
в параметрах функції вже **після деплою**, а через CLI це `verify_jwt = true` у `config.toml`.

Саме через це в додатку розпізнавання працює **тільки після входу** в акаунт:
він надсилає токен сесії в `Authorization`, а publishable-ключ — у заголовку `apikey`
(це рекомендований Supabase порядок).

---

## Крок 5. Користування

**Фото (одна вправа):**
1. **Плани** → редагувати план → **➕ Додати вправу** → режим **📷 Фото**.
2. Обери фото тренажера → **Розпізнати** → підбере схожі з бази.

**Відео або картинки (кілька вправ):**
1. **➕ Додати вправу** → режим **🎬 Відео-файл** → **Відкрити майстер відео**.
2. Завантаж **відео** (повзунок кількості кадрів 6–24) **або кілька картинок** вправ —
   чи те й те разом. Обробка на пристрої, у ШІ йдуть лише кадри-картинки. Тисни **Далі**.
3. **Перевір кадри**: побачиш усі витягнуті кадри з таймкодами. Зніми позначку з зайвих
   (розмитих, повторів). Якщо якоїсь вправи не видно — повернись і збільш кількість кадрів.
4. **Розпізнати** — у ШІ підуть лише позначені кадри (до 8 за раз).
5. Для кожної вправи: збіг із бази або нова «своя» з кадрами. Тисни «＋ У план».
   Посилання на відео (крок 1) прикріпиться до доданих вправ.

> Чому так: кадри беруться рівномірно за часом, тож дуже коротку вправу теоретично можна
> пропустити. Перегляд кадрів і регулятор густоти дають це проконтролювати. Найнадійніше —
> знімати **одну вправу окремим коротким роликом**.

## Якщо не працює

| Повідомлення в додатку | Що робити |
|---|---|
| «Функцію ще не задеплоєно» | Перевір назву функції — має бути точно `recognize` |
| «Спершу увійди в акаунт» | Розпізнавання доступне лише після входу |
| «Не вдалося розпізнати (HTTP_500)» | Не доданий або хибний `ANTHROPIC_API_KEY` |
| «HTTP_401 / 403» | Verify JWT увімкнено, але сесія застаріла — вийди й увійди знову |
| «anthropic 400/429» | Закінчився баланс або перевищено ліміт запитів |

Логи функції: **Edge Functions → recognize → Logs** — там видно точну помилку.
